# PulmoVision AI - Outputs Directory

This directory stores evaluation results, metric logs, and generated analytical charts:

- `evaluation_metrics.json`: Accuracy, Precision, Recall/Sensitivity, Specificity, F1-Score, ROC-AUC.
- `confusion_matrix.png`: High-resolution confusion matrix heatmap.
- `roc_curve.png`: Receiver Operating Characteristic (ROC) curve plot with AUC.
- `precision_recall_curve.png`: Precision-Recall curve with average precision score.
- `classification_report.csv`: Per-class precision, recall, f1-score, and support.
